# Repository guidance

Read [AGENTS.md](AGENTS.md) for project and instrument instructions. Read root [NOTES.md](NOTES.md) and the relevant folder notes before editing. Append a dated entry there when rejecting an alternative, learning a non-obvious constraint, removing something or deferring a choice. Entries have one owning home, are appended in order and never rewritten; the root notes describe the convention and link to each area. Current behavior belongs in README/specification, not duplicated in notes.
