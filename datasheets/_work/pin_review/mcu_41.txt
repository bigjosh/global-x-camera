3.15 Cyclic redundancy check calculation unit (CRC)

                                  The CRC (cyclic redundancy check) calculation un   it is used to get a CRC code from 8-, 16-
                                  or 32-bit data word and a generator polynomial.
                                  Among other applications, CRC-based techniques are used to verify data transmission or
                                  storage integrity. In the scope of the function   al safety standards, they offer a means of
                                  verifying the flash memory integrity. The CRC   calculation unit helps compute a signature of
                                  the software during runtime, to be compared with a reference signature generated at link
                                  time and stored at a given memory location.
