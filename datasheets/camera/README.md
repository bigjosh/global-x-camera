# Camera documentation

> **Archive scope, October 13, 2026:** the documents below support the recovered CAM-5G0-079CLR/VD55G0 circuit. The [current specification](../../spec.md) selects **CAM-6G3-073CLR/VD56G3, 73° diagonal**, for the prototype. Do not apply VD55G0 pin, supply, initialization or optical assumptions to that module without verification. The [prototype parts and camera research record](../../docs/prototype/prototype-parts-and-camera-research.md) captures later selected-module, optics and procurement evidence; the archive described below remains historical source material.

The archive contains the exact **CAM-5G0-079CLR module schematic** (2 pages, Rev 1), **CAM-55G0 DB5266 module brief** (Rev 2), full **VD55G0 DS13170 datasheet** (Rev 10), **UM2829 hardware/software integration and register manual** (Rev 2), **AN5836 visible-domain limitation**, and **TN1478 defective-pixel specification**. Each PDF has an official-source provenance sidecar. Full sensor and register documents were publicly downloadable; no account or NDA was needed.

Use the exact module schematic and DB5266 for the host connector mapping and module mechanics. The module schematic explicitly requires host-side decoupling on VDDIO, VCORE, and VANA. UM2829 complements the sensor datasheet for supply, reset, clock, I2C, streaming, and register configuration. AN5836 should be included in the optical design review because it describes sensitivity to powerful, concentrated visible light even while the sensor is unpowered.

ST lists an exact mechanical model on the [CAM-55G0 CAD resources page](https://www.st.com/en/evaluation-tools/cam-55g0.html#cad-resources): [CAM-5G0-079CLR STEP ZIP](https://www.st.com/resource/en/cad_design_files/cam-5g0-079clr-step.zip). The listing was verified on 2026-09-05, but clicking the download and using the browser file-download action produced no local ZIP. **The STEP model is not archived.** DB5266 still provides module dimensions and connector-to-optical-center spacing; detailed mechanical clearance verification should use the STEP file when obtained.

AN5835 is an older MIPID02 bridge-specific guide. It was identified but intentionally not archived as a design requirement for the STM32N6 native CSI-2 receiver. The full MIPI Alliance standard is not included; the public ST electrical specifications and routing guidance are the available baseline.
