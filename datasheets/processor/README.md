# Processor documentation

These unchanged ST documents cover STM32N657X0H3Q, its VFBGA264 pinout and electrical/mechanical limits, peripheral registers, errata, boot ROM, power design, and PCB interface guidance. Each PDF has a provenance sidecar with its official source URL, retrieval time, size, page count, and SHA-256.

Start with **DS14791 Rev 10 (August 2026)**, **ES0620 Rev 5 (August 2026)**, and **AN5967 Rev 5 (August 2026)**. AN5967 includes the relevant CSI, USB, XSPI, supply, and PCB recommendations. **RM0486 Rev 4 (May 2026)** is the full 4,669-page register reference. **UM3234 Rev 5 (July 2026)** documents boot ROM requirements and boot-interface pin assignments; **AN5050 Rev 14 (June 2026)** supplements XSPI implementation.

AN5946 covers low-power operation. AN6000 is a supplementary **external-core-regulator** reference; it does not cover the internal SMPS currently specified for this project. AN2867, AN2639, and AN1709 cover oscillator design, assembly, and EMC respectively.

The live manufacturer downloads were newer than some search-engine PDF caches. The archived revision, rather than a search result's cached revision, is the baseline for review. Package geometry and numbered pin tables are in DS14791; this archive does not add an independently verified EDA symbol or footprint.
