### From Claude Code or Claude Cowork

In the **ChatGPT desktop app**:

1. Open **Settings → Import**. If that section is missing, look under **Settings → General → Import other agent setup**.
2. Click **Import**.
3. Select **Claude Code** or **Claude Cowork**, then **Continue**.
4. Choose the items you want to bring over, then **Continue**.
5. When it finishes, open an imported chat or project to resume working. :chatgpt-content-reference{index="0"}

Supported items include **chats from the last 30 days**, projects, instructions, settings, skills, plugins, and Claude Code project memories. You can also enable **automatic updates** in Settings → Import to keep imported work synchronized. :chatgpt-content-reference{index="1"}
